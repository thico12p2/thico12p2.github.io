# BT DATA — Obras Públicas RJ

Site de **auditoria de obras públicas do Rio de Janeiro**, feito pela equipe BT DATA (IME) em um hackathon.
Reúne em um só lugar o mapa das obras, um dashboard de auditoria e análises de custos e prazos.

**Acesse:** https://thico12p2.github.io

## Páginas

| Página | O que mostra |
|---|---|
| [Início](https://thico12p2.github.io) | Mapa de geolocalização das obras (Leaflet) e visão geral do projeto |
| [Dashboard](https://thico12p2.github.io/dashboard.html) | Painel de auditoria integrado (Looker Studio) |
| [Análise de Custos](https://thico12p2.github.io/analise_custos.html) | Orçamento previsto × valor gasto, por setor |
| [Análise de Prazos](https://thico12p2.github.io/analise_prazos.html) | Prazo licitado × conclusão real, por região |

## Tecnologias

HTML · Tailwind CSS · JavaScript · Leaflet · Looker Studio · GitHub Pages

Os dados das obras vêm do robô de coleta [extrator-obras-publicas](https://github.com/thico12p2/extrator-obras-publicas).
